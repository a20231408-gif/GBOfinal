# Matriz focalizada

| Requisito | Evidencia ejecutada | Pendiente |
|---|---|---|
| SIC-17/17A/17B válidos desde panel | Compose real, controlador, Room, exportadores y AndroidSharedDocumentStore; tres archivos verificados | Tablet y visor Excel real |
| Incompleto, mensaje y acceso directo | Compose recorre SIC-17 y SIC-17B, motivo por campos reales, navegación al formato; ningún archivo falso | Reproducir estado exacto de la ficha del ingeniero, no disponible |
| SCAP válido | Cinco regresiones del exportador canónico, plantillas originales, logos y fórmulas | Selector/archivo físico de SCAP individual con nombre nuevo |
| Un puente / dos / tres | Incrementos 1–2–3 sobre el mismo nombre; tres formatos independientes | Administrador de archivos de tablet |
| Editar / repetir | Tres filas permanecen; se actualiza una identidad; repetir reutiliza URI y no escribe de nuevo | — |
| Dos rutas | PE-28H y PE-22A en archivos separados; ninguna fila cruzada | — |
| PR, metros, sin PR | Orden numérico desde vínculo SCAP para 17A/B sin columnas técnicas; sin PR al final | Paridad del orden productivo, que en V20 difiere |
| Reapertura | Cierre completo y reapertura de Room en disco, mismo UUID y URI público | Cierre forzado de aplicación real |
| Dos solicitudes simultáneas | Coroutine/IO, mutex y bloqueo de archivo; un principal, sin duplicados | Multiventana/dispositivo físico |
| Pérdida durante escritura | Escritura parcial, journal pendiente, anterior intacto y recuperación | Corte real de proceso/energía |
| Pérdida tras respaldo/promoción | Cancelaciones inyectadas; reintento recupera el mismo journal | Proveedores físicos concretos |
| SAF Android 8/9 | API 28, árbol autorizado, permisos persistentes, carpetas y renombrados que cambian documentId; recuperación de respuesta perdida | Proveedor real de la tablet |
| MediaStore | API 34 con proveedor controlado; ruta/nombre, publicación, hash y respaldo | Visibilidad en Archivos real |
| Otro propietario / destino alterado | No se sobrescribe archivo ajeno, alterado externamente o con nombre inesperado | — |
| Permiso revocado / cancelación | No anuncia éxito y conserva fuentes; journals reanudables | Cancelación del selector SCAP físico |
| Restantes SIC | SIC-19 con observaciones literales y actualización por UUID; SIC-15 por UUID de daño, dos muestras y PR | XLSX remotos de los demás formatos |
| Actualización automática | Triggers reales de Room y trabajos locales existentes: alta, segundo puente y edición actualizan los tres consolidados, sin HTTP/cola remota | Ajuste real de copias automáticas habilitado |
| Dos tablets offline | Contextos, bases y destinos distintos: una fila propia por tablet, sin inventar datos de la otra | Descarga global no implementada ni autorizada |
| Compatibilidad histórica | Rechazo explícito de plantillas SIC-17 incompatibles; conserva último archivo | Conciliar definición contractual con referencia SIC-17 real |
| Estructura y visual | Referencia real no confirmada de Drive y XLSX ficticio, renderizados y revisados; estilos, logos, geometría y tipos comparados | Equivalencia exacta con los consolidados productivos |
| V20 | Tres pruebas Node, fuentes originales, mock Drive; partes XLSX iguales en SIC-17/17A/17B, scope y numeración estables | Google real no ejecutado |
| Conservación | SHA-256 de configuración, esquemas, APK y fuentes backend | No se requiere instalación para esta comprobación |

Los XLSX ficticios están en `evidencias/`; el archivo real y su render se mantienen fuera de Git. No se generó ni distribuyó APK y no se cambiaron servidores.
