# Configuración sin credenciales

Estos ejemplos no habilitan servicios. Usar el perfil de validación existente por parámetro
Gradle; no crear server.local.properties ni drive.local.properties para empezar con mocks.
No se incluyen ejemplos de firma Release porque no es necesaria para desarrollar.
local.properties siempre es propio del equipo y queda ignorado.
